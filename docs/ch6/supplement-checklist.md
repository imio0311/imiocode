- [x] 决策结果使用 `SAFE_COMMAND` 来源标记。（验证：断言决策来源）

- [x] `git status && java -version` 的每个命令段均通过检查并自动放行。（验证：扫描器和检测器测试）

- [x] 重定向、后台执行、命令替换和反引号命令不能自动放行。（验证：扫描器拒绝测试）
