# ch6 权限系统 Checklist

> 每一项通过运行代码或观察行为验证；危险命令只验证检测和“进程未启动”，绝不真实执行。

## 危险命令

- [ ] 系统破坏命令被硬拦截。（验证：运行检测器测试，格式化磁盘、裸设备写入、根目录删除、关机重启和 Fork Bomb 均返回 `DENY`）
- [ ] 项目整体清理被硬拦截。（验证：`git reset --hard`、`git clean -fdx`、递归删除工作区测试均返回 `DENY`）
- [ ] 大小写、额外空白、管道和连续命令不能绕过检测。（验证：跨平台变体测试通过）
- [ ] 正常命令不被误拦截。（验证：`mvn test`、`git status` 和普通只读命令返回非硬拦截结果）
- [ ] `FULL_ACCESS` 和 `allow` 规则不能覆盖危险命令。（验证：权限检查器组合测试通过）

## 路径沙箱

- [ ] 六个核心工具的合法工作区相对目标通过沙箱预检。（验证：沙箱参数化测试通过）
- [ ] 绝对路径和 `..` 越界路径被拒绝。（验证：Windows 与 Unix 风格路径测试通过）
- [ ] 指向工作区外的符号链接被拒绝。（验证：临时目录链接测试通过）
- [ ] Windows Junction 或其他重解析点在平台支持时被拒绝。（验证：Windows 条件测试通过；不支持的平台明确跳过）
- [ ] 写入前路径被替换为链接时仍无法写入。（验证：原子写入复检测试通过）
- [ ] 被沙箱拒绝的调用没有修改工作区外文件。（验证：比较测试前后的外部文件内容）

## 三层规则

- [ ] 用户、项目、本地三个规则文件能独立加载。（验证：规则加载器参数化测试通过）
- [ ] 冲突时用户级优先于项目级，项目级优先于本地级。（验证：三层冲突测试通过）
- [ ] 同层第一条匹配规则生效。（验证：交换规则顺序后结果随之变化）
- [ ] 工具名 glob 和目标 glob 同时生效。（验证：文件路径与 Bash 命令匹配测试通过）
- [ ] 未指定 target 的规则匹配该工具全部目标。（验证：无 target 规则测试通过）
- [ ] 无效 YAML、未知字段、非法 action/mode/glob 阻止启动。（验证：加载器异常测试和应用启动测试通过）
- [ ] 所有规则文件都缺少 mode 时使用 `ASK`。（验证：默认配置测试通过）
- [ ] mode 按用户、项目、本地优先级选取。（验证：分层 mode 冲突测试通过）

## 五种权限模式

- [ ] `LOCKDOWN` 拒绝全部工具且规则不能放行。（验证：六工具参数化测试）
- [ ] `READ_ONLY` 允许读取/搜索，拒绝写入/Bash，规则不能突破上限。（验证：六工具参数化测试）
- [ ] `ASK` 自动允许读取/搜索，写入/Bash 返回 `ASK`。（验证：模式策略测试）
- [ ] `AUTO_EDIT` 自动允许读取/搜索/写入，Bash 返回 `ASK`。（验证：模式策略测试）
- [ ] `FULL_ACCESS` 默认允许普通操作，但显式 `ask`、`deny` 仍生效。（验证：模式与规则组合测试）
- [ ] 危险命令和沙箱拒绝在全部五种模式下保持不变。（验证：五模式参数化测试）

## 统一检查和调度

- [ ] 权限顺序为危险命令、沙箱、模式上限、规则、模式默认值。（验证：为同一请求配置多个冲突条件，检查决策来源）
- [ ] 权限组件异常时按拒绝处理。（验证：注入抛异常的检测器或沙箱替身）
- [ ] `DENY` 调用不进入工具线程池、不产生 QUEUED/RUNNING 执行事件。（验证：调度器监听器测试）
- [ ] `ASK` 调用在确认前不启动。（验证：阻塞确认时工具执行计数保持为 0）
- [ ] 明确允许的 LOW 工具仍可在模型流期间提前执行。（验证：流式调度回归测试）
- [ ] ASK 屏障后的工具不会抢跑。（验证：混合批次执行顺序测试）
- [ ] 混合 ALLOW/ASK/DENY 结果按原始工具索引回传。（验证：结果顺序测试）
- [ ] 权限拒绝作为失败 `tool_result` 回传，Agent 可继续下一轮。（验证：Agent 集成测试）

## HITL 与终端

- [ ] 权限请求事件包含请求 ID、工具、风险、目标摘要和原因。（验证：Agent 事件测试）
- [ ] 终端正确显示确认信息且敏感内容已脱敏。（验证：虚拟终端输出测试）
- [ ] 输入 `1` 或 `once` 只允许当前调用。（验证：相同调用第二次仍请求确认）
- [ ] 输入 `2` 或 `session` 放行本会话中相同工具和相同规范化目标。（验证：第二次等价调用不再询问）
- [ ] 会话授权不会放行不同工具或不同目标。（验证：近似目标仍请求确认）
- [ ] 输入 `3` 或 `deny` 返回拒绝工具结果。（验证：确认与 Agent 集成测试）
- [ ] 非法输入会重新提示，不会默认允许。（验证：虚拟终端输入序列测试）
- [ ] EOF、Ctrl+C、任务超时和会话关闭会拒绝并唤醒等待请求。（验证：取消测试在限定时间内结束）
- [ ] 重复回复和未知请求 ID 不改变已完成决策。（验证：协调器并发测试）
- [ ] 多个 ASK 按工具调用顺序逐个展示。（验证：两个请求的事件和提示顺序一致）
- [ ] 确认期间 UI 状态为 `PERMISSION_WAITING`，普通对话输入不抢占确认输入。（验证：ConversationLoop 测试）

## Agent 与模式集成

- [ ] Plan Mode 只暴露和执行读取、搜索工具。（验证：既有 Plan Mode 测试继续通过）
- [ ] Plan Mode 的读取仍受沙箱和显式 deny 规则约束。（验证：Plan Mode 权限组合测试）
- [ ] Do Mode 使用配置的权限模式，不绕过权限闸门。（验证：写入或 Bash 请求产生预期决策）
- [ ] Agent 取消和超时同时停止 LLM、工具及待确认请求。（验证：AgentCancellationTest）
- [ ] 会话临时授权跨正常轮次保留，会话关闭后清空。（验证：ConversationSession 集成测试）
- [ ] 流式文本、Thinking、Usage 和既有工具状态展示不受影响。（验证：相关回归测试全部通过）

## 编译与测试

- [ ] Java 21 编译成功。（验证：`mvn -DskipTests compile`）
- [ ] 权限模块单元测试全部通过。（验证：运行对应权限测试类）
- [ ] Agent、Conversation、Terminal 和 Workspace 集成测试通过。（验证：运行相关测试类）
- [ ] 全部既有及新增测试通过。（验证：`mvn test`，0 failures、0 errors）
- [ ] 可执行 JAR 打包成功。（验证：`mvn -DskipTests package`）
- [ ] JAR 能正常启动并响应退出命令。（验证：启动后输入 `/exit`，进程正常结束）

## 端到端场景

- [ ] 场景 1：要求 Agent 读取入口文件，读取工具自动执行并生成正确回答。
- [ ] 场景 2：要求 Agent 修改临时测试文件，终端弹出确认；选择“允许一次”后文件发生预期变化。
- [ ] 场景 3：连续执行两次相同安全命令，首次选择“本次会话允许”，第二次不再询问。
- [ ] 场景 4：对文件修改选择“拒绝”，文件保持不变，Agent 收到拒绝结果并给出替代说明。
- [ ] 场景 5：请求 `mvn test`，在允许后执行并将退出码与输出回传给模型。
- [ ] 场景 6：在 `FULL_ACCESS` 和显式 allow 规则下请求项目整体清理，仍显示硬拦截且命令进程未启动。
- [ ] 场景 7：请求读取工作区外文件或符号链接目标，调用被拒绝且外部文件保持不变。
- [ ] 使用 tmux 启动 ImioCode、输入真实请求并保存终端证据；若当前 Windows 环境无法提供 tmux，记录实际限制，并用可用真实终端完成等价交互测试。
